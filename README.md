One line of weather forecast for a city that does not exist, for the
make.fun bounty "Charm the Commuter: Forecast a City That Isn't". The
program writes a single 121-character line to `/output/entry.txt`:

> In Brollywick, drizzle till nine, then sunshine — the ducks queue at the crossing and your umbrella gets the morning off.

## Run it

```sh
node main.ts
```
